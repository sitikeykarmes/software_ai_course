This course is written to be complete on its own for the concepts. The material below is for the two things a written course cannot give: long practice sets, and official documentation for the exact syntax of tools that change. Everything listed is free unless marked. Links open in a new tab and need internet access.

Selection was checked in November 2026 against several independent 2026 course comparisons. Offerings and prices change, so confirm on the site itself.

## How to use these without getting lost

- Pick **one** resource per topic and finish it. Collecting courses is not learning.
- Use them alongside the matching lesson here, not instead of building.
- Prefer official documentation for anything about a tool's current behaviour.

## Programming and Python

| Resource | What it is | Use it for |
| --- | --- | --- |
| [The Python Tutorial](https://docs.python.org/3/tutorial/) | The official tutorial | The authoritative reference for the language |
